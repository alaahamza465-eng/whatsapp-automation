# whatsapp-automation — سكيل لـClaude بيبنيلك نظام حملات واتساب على n8n

بتحكي لـClaude عن شغلك، وبيمشي معك خطوة خطوة لحد ما يصير عندك نظام حملات واتساب شغّال، **بربط رسمي مع ميتا** (WhatsApp Cloud API):

- **إرسال على دفعات** من كشف أرقام، بالسرعة والساعات والأيام اللي بتحددها، وبحد يومي بيكبر شوي شوي.
- **رسالة بزرّين:** «بدي التفاصيل» و«مش مهتم». المهتم بيوصله ردك لحاله، واللي مش مهتم ما بيوصله إشي بعدها.
- **لوحة تحكم عربية على الجوال:** حملات، حتى 3 نسخ من الرسالة، وتجربة بتوريك إذا الرسالة وصلت فعلًا أو ليش ما وصلت.
- **صندوق محادثات وإشعارات:** حدا رد؟ بيوصلك تنبيه، وبترد عليه من نفس اللوحة.
- **تتبّع وتقارير:** مين وصلته، مين فتحها، مين رد، وتقرير Excel بكبسة.
- **حماية الرقم:** بيوقف لحاله إذا نزلت الجودة أو زاد «مش مهتم»، وبيتعامل صح مع حد ميتا لرسائل التسويق (131049).

بيشتغل لأي دولة (مفتاح الدولة والمنطقة الزمنية من الإعدادات). القوالب الأربعة جاهزة للاستيراد، وسكربت بيعبّيها بأرقام جداولك.

> **الدليل الكامل خطوة بخطوة (PDF):** `guide-ar.pdf` — إيش بيعمل، التثبيت، أول استعمال، نصائح، وحل المشاكل.

## إيش لازم يكون عندك
- **n8n** على سيرفرك (نسخة فيها Data Tables).
- **حساب Meta Business** ورقم واتساب للأعمال على Cloud API.
- **Claude** مع تشغيل الكود. والأحسن لو عنده متصفح (Claude in Chrome) عشان يعمل الخطوات عنك.

## التثبيت

### تطبيق Claude (claude.ai / الديسكتوب)
1. نزّل ملف السكيل من قسم Releases، مش من زر Code، لأنه هداك بيغيّر اسم المجلد والسكيل ما بيشتغل:

   https://github.com/alaahamza465-eng/whatsapp-automation/releases/latest/download/whatsapp-automation.zip

2. فعّل «Code execution and file creation» من الإعدادات.
3. روح على **Customize > Skills** ← زر **+** ← **Create skill** ← **Upload a skill**.
4. ارفع ملف `whatsapp-automation.zip` زي ما هو، بدون ما تفكّه.

### Claude Code
انسخ مجلد `whatsapp-automation` لـ:

```
~/.claude/skills/whatsapp-automation/
```

وعلى ويندوز:

```
%USERPROFILE%\.claude\skills\whatsapp-automation\
```

وبعدين افتح Claude Code من جديد.

## الاستعمال
اكتب لـClaude مثلًا:
> بدي أبني نظام حملات واتساب على n8n تبعي

Claude بيسألك سؤال سؤال (دولتك، منطقتك الزمنية، رابط n8n، وين وصلت مع ميتا)، وبيجهّزلك الملفات، وبيجرّب معك أول رسالة قبل أي حملة حقيقية.

**ولا مرة بتحط مفتاح ميتا (Token) بالمحادثة.** بتحطه بنفسك جوا n8n.
