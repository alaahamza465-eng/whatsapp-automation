# ملاحظات n8n (أشياء بتكسر بصمت)

- **داخل عقد Data Table و Respond to Webhook:** التعبير `$('اسم العقدة')` ممكن يطلع فاضي. استعمل `$node["اسم العقدة"].json` أو `$json`.
- **صفحات الـ Webhook محمية (CSP sandbox):** ما في localStorage ولا service worker ولا إشعارات Push من صفحة `/webhook/wac` نفسها. اللوحة بتحفظ بالذاكرة، والتنبيه بيوصل واتساب برابط. للـ Push الحقيقي اعرض الصفحة من موقع عادي (مثل GitHub Pages) بيجيب الصفحة من n8n ويحط `window.WAC_API`.
- **أسماء ملفات التنزيل** لازم تكون إنجليزي بصفحات الـ sandbox، وإلا بتنزل باسم `download`.
- **ترتيب التنفيذ v1:** فروع نفس العقدة بتمشي من فوق لتحت حسب مكانها بالشاشة. `Chat Status Now` لازم يضل فوق `Wait Status`، وإلا بيستنى 45 ثانية.
- **Wait أقل من 65 ثانية** بيوقف نفس التنفيذ بالذاكرة. ما تطوّله.
- **Execute Workflow** (v1.1، بدون انتظار) بيستدعي workflow الإشعارات. بـ n8n 2.x لازم يكون منشور.
- **النشر بـ 2.x:** الحفظ بيعمل مسودة، والتعديل ما بيمشي قبل Publish.
- **Code بوضع Run once for each item** (مثل `Result`): `$('Decide').item` بيرجع العنصر المقابل.
- **الأعمدة كلها string:** قارن التواريخ كنص بصيغة `yyyy-MM-dd HH:mm`، وهيك القيم القديمة `yyyy-MM-dd` بتشتغل معها.
- **فلتر `neq` بجداول n8n** بيشمل الخانات الفاضية (`IS NULL`). عليه مبني منع «وصلت» من الكتابة فوق «انقرت».
- **الصفحة HTML كاملة جوا `Send Page`.** إذا عدّلتها، عدّل النص كامل وانشر، وجرّب بالجوال.
